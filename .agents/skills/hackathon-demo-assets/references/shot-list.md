## Recording settings

- Desktop: 1920x1080, browser zoom 100-110%, clean profile, no bookmarks bar, notifications off.
- Phone: native screen recording, do-not-disturb on, battery and clock tidy.
- Slow cursor; pause 1 s on every state change; record each beat twice.
- Capture system audio only when voice is part of the demo.
- Name files by shot: `C3-beat-b-take2.mp4`.

## Video checklist before upload

- [ ] Length within the event rule (usually 1-3 min)
- [ ] Cold open is real product footage
- [ ] Beat A and Beat B both visible (or one clearly primary path)
- [ ] Numbers match FACTS; claimed live integrations have current health and real operation proof; tools and limits are described honestly
- [ ] URL spoken and on screen for at least 3 s
- [ ] Captions burned in; loudness fine on laptop speakers
