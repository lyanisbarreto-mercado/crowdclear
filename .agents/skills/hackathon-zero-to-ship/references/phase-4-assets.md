# Phase 4: Demo assets

REQUIRED SUB-SKILL: `hackathon-demo-assets`. It owns the shot list, captures, brand kit, video edit, gallery and expo poster.

Start shot planning, narration/copy and brand assets in parallel once the brief is clear. Capture product footage from a verified stable commit/deployment after the relevant hardening checks. Freeze the recorded path, rather than blocking all asset preparation until every feature is finished.

Read the actual event requirements first. Video, gallery counts, public hosting and posters below are web/Devpost defaults; skip inapplicable assets with a reason in PLAN. A permitted local demo uses its verified local build as the captured environment.

## Handoff

- Record the commit/deployment URL and capture time in the asset notes.
- Keep `docs/FACTS.json` current; every spoken number needs measured provenance. Avoid claiming latency or cost unless measured.
- Fill Beat A/B in `docs/pitch.md` ([pitch-formula.md](pitch-formula.md)).
- Reuse `docs/design/BRAND.md`; use real product captures for UI evidence.
- If the product changes, identify affected scenes and re-record those scenes. Recheck the final video's claims against the final deployment.

Target upload by about T-15% of the event ([timeline.md](timeline.md)). Finish export, thumbnail, captions, gallery and a ready-to-upload package before requesting any missing upload/publication authorization. Existing authorization persists; guided mode continues through authorized actions. Record pending external upload as pending, not complete.

## Checkpoint before Phase 5

- Required video exported and watchable; uploaded link recorded when required and authorized, otherwise package ready and blocker explicit.
- Required thumbnail/gallery readable and aligned with the event's count/format.
- Captures show the real signature path, preferably both beats, and how judges try it.
- Claims match the captured environment; sandbox and fixtures are labelled.

Report the asset package and remaining action, then follow [autonomy.md](autonomy.md).
